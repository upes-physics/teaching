🎓 Fundamental Concepts

An amplifier is an electronic device that increases the power of a signal. The classification of amplifiers (A, B, AB, C) is based on the conduction angle (θ) — the portion of the input cycle during which the output transistor conducts. The Q-point (Quiescent Point) on the DC load line determines the class of operation.

🟢

Class A Amplifier

The transistor conducts for the full 360° of the input cycle. The Q-point is set at the centre of the load line (active region). Output is a faithful replica of input — no distortion. However, efficiency is very poor (max ~25–50%) because current flows even with no signal.

θ = 360° Eff: 25–50%
Audio AmplifiersLow PowerHigh Fidelity
🔵

Class B Amplifier

Uses two complementary transistors in a push-pull configuration. Each transistor conducts for exactly 180°. Q-point is at cut-off. Efficiency improves to ~78.5% but suffers from crossover distortion near the zero-crossing point (±0.7V dead band).

θ = 180° Eff: ~78.5%
Push-PullAudio OutputBattery Devices
🟡

Class AB Amplifier

A compromise between A and B. Both transistors conduct for slightly more than 180° (between 180°–360°). Small forward bias eliminates crossover distortion while maintaining ~60–70% efficiency. Most widely used in audio power amplifiers.

180° < θ < 360° Eff: 50–70%
HiFi AudioPower AmpsBest Compromise
🔴

Class C Amplifier

Conducts for less than 180° of the input cycle (~90°–120°). Biased below cut-off. Highest efficiency (~80–90%) but extremely high distortion. Requires a tuned resonant tank circuit to reconstruct the waveform. Used in RF transmitters.

θ < 180° Eff: 80–90%
RF TransmittersTuned CircuitsNOT Audio
📍

Q-Point (Quiescent Point)

The DC operating point of a transistor when no AC signal is applied. It's the intersection of the DC load line with the transistor's characteristic curve. The Q-point determines the amplifier class: centre = Class A, cut-off = Class B, below cut-off = Class C.

IC(Q)VCE(Q)Load Line
📐

Conduction Angle (θ)

The electrical angle (in degrees) for which the output device is conducting current. Class A: 360°, Class B: 180°, Class AB: 180–360°, Class C: <180°. As θ decreases, efficiency increases but distortion worsens.

θ = 2π (Class A)θ = π (Class B)
⚡

Crossover Distortion

A non-linearity that occurs in Class B amplifiers at the zero-crossing point. Neither transistor conducts in the ±0.7V dead band (V_BE threshold), creating a glitch in the output waveform. Class AB eliminates this with slight forward biasing.

Class B Problem±0.7V Dead Band
🔁

Push-Pull Configuration

Used in Class B and AB. Two complementary transistors (NPN + PNP) share the load. The NPN conducts on positive half-cycles, PNP on negative. Combined output reconstructs the full waveform, improving efficiency while delivering both polarities.

NPN+PNP PairComplementary
