Basic concept knowledge

How rectifiers convert AC into unidirectional output

A rectifier uses the one-way conduction property of a diode. A resistive load then receives current in one direction only. The output is pulsating DC, not perfectly steady DC. This learning lab focuses only on half-wave, centre-tapped full-wave, and bridge rectification so that the conduction paths remain clear.

1

Half-wave rectifier

One diode conducts during one half-cycle and blocks the other half-cycle. Only half of the available AC waveform reaches the load.

  • One diode; one conducting half-cycle.
  • Output ripple frequency equals the input frequency, f.
  • High ripple and relatively low conversion efficiency.
  • Peak inverse voltage per diode is approximately Vp.
Ideal: Vdc = Vp/π, ripple factor ≈ 1.21, maximum rectification efficiency ≈ 40.6%.
2a

Full-wave, centre-tapped

A centre-tapped transformer provides two equal secondary voltages that are 180° out of phase. The two diodes conduct alternately, but load current keeps the same direction.

  • Two diodes; only one conducts at a time.
  • Requires a centre-tapped transformer.
  • Output ripple frequency is 2f.
  • Each diode must withstand a PIV of approximately 2Vp.
Ideal: Vdc = 2Vp/π, ripple factor ≈ 0.482, maximum rectification efficiency ≈ 81.2%.
2b

Full-wave bridge

Four diodes form a bridge. A diagonal pair conducts on each half-cycle, steering load current in one direction without a centre tap.

  • Four diodes; two conduct in series at a time.
  • No centre-tapped transformer is required.
  • Output ripple frequency is 2f.
  • Two forward drops reduce the available peak output.
Practical peak: Vo,pk ≈ Vp − 2VF. PIV per diode is approximately Vp.

Important terms

Average DC value

The mean output voltage over a complete cycle. It represents the DC component delivered to the load.

RMS value

The effective value that produces the same heating effect in the load as an equivalent DC voltage.

Ripple factor

r = Vac,rms/Vdc = √[(Vrms/Vdc)² − 1]. Lower values mean smoother pulsating DC.

Peak inverse voltage

The maximum reverse voltage a non-conducting diode must safely withstand.

About the simulator model

The live calculations use a resistive load and a constant diode forward-drop model. Conduction begins only when the instantaneous source magnitude exceeds the required diode drop. Therefore, the numerical averages are slightly more realistic than the simplest textbook approximation. Set VF = 0 V to recover the ideal-diode results.
