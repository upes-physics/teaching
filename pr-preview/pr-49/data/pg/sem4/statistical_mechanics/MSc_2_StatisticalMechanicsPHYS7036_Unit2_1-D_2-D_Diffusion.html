Concept: Diffusion Equation and Numerical Simulation

Diffusion describes the spontaneous spreading of a concentration or density from regions of high concentration toward regions of low concentration. Its evolution is governed by the diffusion equation, $\frac{\partial n}{\partial t}=D\nabla^2n$, where the diffusion coefficient $D$ determines how rapidly the profile spreads. In a numerical simulation, the continuous equation is replaced by a finite-difference scheme, whose stability depends on the dimensionless parameter $\alpha=D\Delta t/\Delta x^2$. Thus, the simulator allows us to explore both the physical behaviour of diffusion and the importance of choosing appropriate numerical parameters for a stable solution.

Quiz Questions

Test your understanding of diffusion dynamics, boundary conditions, and numerical stability CFL criteria.

Q1. Effect of the Diffusion Coefficient

Select the Gaussian (Delta-like) initial condition and use the 1D Analysis mode. Set $D = 0.1\text{ m}^2/\text{s}$ and run the simulation for some time. Reset the simulation, change $D$ to $1.0\text{ m}^2/\text{s}$, and run it again. What do you observe?

Correct Answer: A

The diffusion coefficient determines the rate at which concentration gradients smooth out. The simulator directly uses $D$ in the diffusion update equation.

Q2. Diffusion and Peak Concentration

Use the Gaussian (Delta-like) initial condition with $D = 0.5\text{ m}^2/\text{s}$. Run the simulation and observe the concentration profile and the Peak Concentration displayed below the graph. What happens to the peak concentration as diffusion proceeds?

Correct Answer: A

As the initially localized concentration spreads, the profile becomes broader and its maximum concentration decreases. This illustrates the smoothing effect of diffusion. The simulator explicitly tracks the peak concentration during the evolution.

Q3. Effect of Boundary Conditions

Select the Step Function as the initial condition and use the 1D Analysis mode. Compare the following three boundary conditions:

  • Dirichlet (Fixed 0)
  • Neumann (Insulated)
  • Periodic

Run each case for a comparable amount of time. Which statement best describes the difference you observe?

Correct Answer: A

The simulator implements the three boundary conditions differently: Dirichlet fixes the boundary value to zero, Neumann uses an insulated/no-flux condition, and periodic boundaries connect the two ends.

Q4. Numerical Stability and the CFL Condition

Keep the 1D Gaussian initial condition and gradually increase the Time Step $\Delta t$ while keeping $D$ fixed. Watch the displayed CFL factor

$$\alpha = \frac{D \Delta t}{\Delta x^2}$$

What happens as $\alpha$ approaches and exceeds 0.5?

Correct Answer: A

This is an important numerical-analysis concept: for the 1D FTCS scheme used here, the simulator identifies $\alpha \le 0.5$ as the stable range and warns of instability above this limit.

This question is particularly valuable because the student sees numerical instability rather than simply memorizing the CFL condition.

Q5. From 1D to 2D Diffusion

Select the Gaussian (Delta-like) initial condition. First run the simulation in 1D Analysis mode and observe the spreading profile. Then switch to 2D Thermal mode and run the simulation with the same diffusion coefficient. What fundamental difference does the 2D simulation demonstrate?

Correct Answer: A

The simulator implements a 1D Laplacian in the first mode and a 2D Laplacian involving four neighbouring grid points in the second mode.
