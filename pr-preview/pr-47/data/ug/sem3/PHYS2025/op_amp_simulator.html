Operational amplifiers turn feedback into useful mathematics.

An op-amp amplifies the voltage difference between its non-inverting and inverting terminals. Negative feedback makes the enormous open-loop gain behave as a stable, predictable closed-loop circuit.

Foundation

The two ideal analysis rules

For an ideal op-amp operating linearly with negative feedback:

  • No current enters either input terminal.
  • The feedback drives V+ ≈ V−.
i+ = i− = 0    and    V+ ≈ V−
Reality check

Why practical waveforms distort

A real device has finite output swing, finite gain-bandwidth product and finite slew rate. The simulator's μA741 model uses typical educational values of 1 MHz GBP and 0.5 V/μs slew rate.

Vpk,max(slew) = SR / (2πf)

Inverting amplifier

The source drives the − input through Rin. The + input is grounded. Feedback through Rf creates a 180° phase reversal.

Av = −Rf / Rin

Non-inverting amplifier

The signal drives the + input directly. A feedback divider sets a positive gain, so output and input remain in phase.

Av = 1 + Rf / Rin

Summing amplifier

Currents from several sources meet at the inverting summing node. Their weighted sum appears at the output with inverted polarity.

Vout = −Rf (V1/R1 + V2/R2 + …)

Difference amplifier

A matched four-resistor network subtracts one input from another. Accurate resistor ratios are essential for good common-mode rejection.

Vout = (Rf/Rin)(V2 − V1)

Differentiator

A capacitor at the input and resistor in feedback make output proportional to the rate of change. For a sine input, the inverting differentiator shifts phase by −90°.

Vout = −RC · dVin/dt

Integrator

A resistor at the input and capacitor in feedback accumulate the signal over time. For a sine input, the ideal inverting integrator shifts phase by +90°.

Vout = −(1/RC) ∫ Vin dt

How to investigate

Three quick experiments

  • Gain and clipping: choose the inverting circuit, increase Rf, and watch the calculated output demand exceed ±Vsat.
  • Gain-bandwidth trade-off: choose the μA741 model, set a large closed-loop gain, then raise frequency and observe attenuation plus extra phase lag.
  • Slew-rate limit: use the “Slew limit” preset. The practical output changes from a sine toward a slope-limited waveform even before rail clipping is dominant.
