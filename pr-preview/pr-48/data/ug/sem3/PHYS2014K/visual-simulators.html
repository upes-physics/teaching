Computational Physics: Visual Simulators

Interactive visual aids for projectile motion and data analysis with Gnuplot.

10. Horizontal Projectile

Visualize the trajectory of a projectile projected horizontally from a height.

11. Oblique Projectile

Plot the trajectory of a projectile projected at an angle with the horizontal.

12(a). Linear Regression

Enter x-y data and visualize the best-fit straight line. Also generate matching Gnuplot commands.

12(b). Cubic Spline Smoothing

Show how smooth curves pass through measured data points. The simulator uses piecewise smooth interpolation for classroom visualization.

12(c). Bezier Curve

Move the control values and see how a cubic Bezier curve is shaped by its control points.

12(d). Hermite Interpolation

Visualize cubic Hermite interpolation using endpoint values and endpoint slopes.
