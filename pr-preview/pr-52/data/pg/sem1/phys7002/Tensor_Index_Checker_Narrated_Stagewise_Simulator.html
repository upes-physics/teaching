Layer 1 - Conceptual Understanding

Tensor Index Manipulation

Tensor notation uses upper and lower indices to represent components, contractions, and coordinate transformation behavior. This checker focuses on index consistency.

Learning Outcomes

  • Distinguish free and dummy indices.
  • Check whether free indices match on both sides of an equation.
  • Detect invalid repeated indices.
  • Understand contraction using one upper and one lower repeated index.
  • Recognize raising and lowering operations with the metric tensor.

Free Indices

Free indices appear once in a term and must match on both sides.

Dummy Indices

A dummy index appears exactly twice, once up and once down, and is summed over.

METRIC

Raise/Lower

The metric tensor changes index position, such as \(v_i=g_{ij}v^j\).

1. Einstein Summation Convention

\[ A^i{}_jB^j{}_k=C^i{}_k \]

The repeated index \(j\) is dummy because it appears once up and once down. The free indices are \(i\) and \(k\), so the result must also carry \(i,k\).

2. Validity Rules

RuleMeaning
Free-index matchingEach side of an equation must have the same free indices in the same variance position.
Dummy-index pairA contracted index should appear exactly twice in a term, once upper and once lower.
No triple repetitionAn index repeated three or more times in one term is usually invalid.
Metric use\(g_{ij}v^j=v_i\) lowers an index; \(g^{ij}v_j=v^i\) raises an index.

Layer 3 - Exploration & Applications

Applications

Differential Geometry

Tensor indices track how geometric quantities transform under coordinate changes.

Relativity

Raising, lowering, contraction, and curvature expressions are central in relativity notation.

Continuum Mechanics

Stress, strain, and elasticity tensors use index notation to represent multi-directional behavior.

Computational Tensor Algebra

Index notation helps verify array contractions used in scientific computing and machine learning.

Instructor & Student Support

Teaching Notes

Suggested Sequence

  1. Begin with free indices as the visible output labels.
  2. Introduce dummy index contraction.
  3. Show free-index mismatch errors.
  4. Show repeated-index errors.
  5. Demonstrate metric raising and lowering.

Common Errors

  • Using a dummy index on one side as a free index on the other.
  • Repeating an index three times in one term.
  • Contracting two upper or two lower indices without a metric.
  • Changing variance position of free indices without justification.
