Concept: Statistical Origin of Entropy

In statistical mechanics, entropy arises from the number of microscopic configurations, or microstates, compatible with a given macroscopic state. If $W$ is the number of microstates corresponding to a macrostate, Boltzmann's relation gives $S=k_B\ln W$. For $N$ particles distributed between two regions, $W=\frac{N!}{n_L!n_R!}$, so the entropy is largest for macrostates with nearly equal numbers of particles on both sides. Thus, the tendency toward thermodynamic equilibrium can be understood statistically: equilibrium is overwhelmingly likely because it corresponds to the largest number of accessible microstates.

Q1. Entropy and Approach to Equilibrium

Set the number of particles to $N = 50$ and use INJECT ALL LEFT to start with all particles on the left. Run the simulation and observe the particle distribution and the entropy $S/k_B$ as time progresses. Which statement best describes what you observe?

Correct Answer: A

The important observation is that the initially ordered state has very low multiplicity ($W = 1$), whereas more evenly distributed states have enormously greater multiplicity. The simulator starts in this constrained state specifically to demonstrate entropy growth.

Q2. Which Macrostate Has the Maximum Entropy?

Set $N = 50$ and allow the system to evolve. Observe the values of $n_L, n_R, W$, and $S/k_B$. Which macrostate should have the largest multiplicity and therefore the largest entropy?

Correct Answer: C

For $N = 50$,

$W = \frac{50!}{n_L! n_R!}$

is largest when the particles are distributed as evenly as possible between the two sides. Since $S = k_B \ln W$, this macrostate also has the largest entropy. The simulator calculates this multiplicity for the instantaneous macrostate.

Q3. Entropy Depends on Multiplicity, Not Just Particle Distribution

Run the simulator several times with $N = 50$, starting with INJECT ALL LEFT. Watch the values of $W$ and $S/k_B$ as $n_L$ changes. Which observation best demonstrates the statistical meaning of entropy?

Correct Answer: A

This question makes students connect the visual particle distribution to the mathematical quantity $W$, rather than simply memorizing $S = k_B \ln W$. The simulator updates $W$ and $S/k_B$ continuously from the instantaneous $n_L, n_R$.

Q4. Effect of Increasing the Number of Particles

First set $N = 20$ and observe the probability distribution $P(n_L)$. Then increase the number of particles to $N = 100$. What happens to the theoretical probability distribution?

Correct Answer: A

The simulator calculates

$P(n_L) = \frac{W(N, n_L)}{2^N}$

so increasing $N$ makes the distribution increasingly concentrated around the equilibrium macrostate $n_L \approx N/2$.

This is an especially important statistical-mechanics idea: equilibrium does not mean that other macrostates are impossible; it means that the equilibrium macrostate is overwhelmingly more probable for a large system.

Q5. Does Particle Speed Determine the Equilibrium Entropy?

Set $N = 50$. Run the simulation with the mean speed first at $v = 1\text{ m/s}$ and then at $v = 8\text{ m/s}$. In both cases start with INJECT ALL LEFT and observe the long-time behaviour. Which statement is most appropriate?

Correct Answer: A

The speed of particles dictates how fast they cross the partition, but the equilibrium spatial distribution depends solely on spatial microstate multiplicity $W = \frac{N!}{n_L! n_R!}$.
