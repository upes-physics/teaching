FORTRAN 90 Programming Simulator

Static simulators for Unit 2: variables, operators, branching, loops, arrays, subroutines, file I/O and modules.

Unit 2: Scientific Programming using FORTRAN 90

These activities help students understand FORTRAN 90 syntax without needing an online compiler. Each simulator shows code, logic and expected output.

1. Variables and Arithmetic Expressions

Change two numbers and observe how assignment and arithmetic operators work.

program arithmetic_demo implicit none integer :: a, b, c a = 5 b = 3 c = a + b print *, c end program arithmetic_demo

2. Relational Expression and Block IF

Check whether a number is positive, negative or zero using an IF block.

program if_demo implicit none integer :: x if (x .gt. 0) then print *, 'Positive' else if (x .lt. 0) then print *, 'Negative' else print *, 'Zero' end if end program if_demo

3. SELECT CASE Simulator

Choose an integer menu option and see how SELECT CASE branches.

select case(choice) case(1) print *, 'Addition selected' case(2) print *, 'Subtraction selected' case(3) print *, 'Multiplication selected' case default print *, 'Invalid choice' end select

4. DO Loop Simulator

Print values of a loop variable from 1 to n.

program loop_demo implicit none integer :: i, n do i = 1, n print *, i end do end program loop_demo

5. Array Reading and Sum

Enter array values and calculate sum and average.

real :: x(5), sum, average integer :: i sum = 0.0 do i = 1, 5 sum = sum + x(i) end do average = sum / 5.0

6. Function and Subroutine Concept

Compare a function that returns a value and a subroutine that modifies/output values.

real function area_circle(r) real, intent(in) :: r area_circle = 3.14159 * r * r end function area_circle call show_area(r, area)

7. Disk I/O Statement Generator

Generate basic FORTRAN 90 code for opening, writing and closing a file.

open(unit=10, file='output.dat', status='replace') write(10,*) x, y close(10)

8. Module and User-defined Type

Generate a simple module skeleton for defining constants and derived types.

module physics_types implicit none type :: particle real :: mass real :: charge end type particle end module physics_types
