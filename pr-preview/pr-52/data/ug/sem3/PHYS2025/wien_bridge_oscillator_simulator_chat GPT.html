Correct circuit and signal path

The non-inverting input receives frequency-selective positive feedback through the Wien lead–lag network. The inverting input receives ordinary negative feedback through Rf and Rg, which sets the amplifier gain.

How one loop works

1. A tiny disturbance appears

Power-on noise contains many frequencies. The Wien network favors the frequency at which its phase shift is zero.

2. The RC network selects f₀

The series C₁–R₁ arm and shunt R₂∥C₂ arm form a lead–lag divider. At f₀, its output is in phase with Vout.

3. The op-amp restores loss

The non-inverting gain A compensates the feedback attenuation β₀. Sustained oscillation requires Aβ₀ = 1.

4. Amplitude is limited

Real oscillators need an amplitude-control element. Without it, excess gain drives the op-amp into clipping.

Complete loop

Both feedback paths are essential: the Wien network chooses the frequency and phase, while Rf and Rg set how much the op-amp amplifies.

Basic concept knowledge

A Wien bridge oscillator is a sinusoidal RC oscillator. It combines a frequency-selective positive-feedback network with a non-inverting amplifier and a separate amplitude-stabilization mechanism.

1. What is an oscillator?

An oscillator converts DC supply power into a periodic AC signal without requiring a continuing external input signal. A small start-up disturbance is repeatedly amplified and fed back.

The desired frequency survives when the total loop phase is 0° (or 360°) and the loop magnitude is one.

2. Barkhausen criterion

For steady sinusoidal oscillation at one frequency:

|Aβ| = 1   and   ∠Aβ = 0°

For reliable start-up, the small-signal loop gain is usually made slightly greater than one; amplitude control later reduces it to one.

3. Wien lead–lag network

The positive-feedback network has a series C₁–R₁ arm and a shunt R₂∥C₂ arm. It behaves like a band-pass network: very low and very high frequencies are strongly attenuated.

At the balance frequency, the network phase shift is exactly 0°.

4. Oscillation frequency

For equal components R₁ = R₂ = R and C₁ = C₂ = C:

f₀ = 1 / (2πRC)

For unequal values:

f₀ = 1 / (2π√(R₁R₂C₁C₂))

5. Feedback fraction and gain

For equal components, the Wien network attenuates the output to one third at f₀, so β₀ = 1/3. The non-inverting amplifier must therefore have a gain of three.

A = 1 + Rf/Rg = 3 ⇒ Rf = 2Rg

For unequal components, Areq = 1 + R₁/R₂ + C₂/C₁.

6. Growth, decay, and clipping

  • Aβ < 1: every trip around the loop is smaller, so oscillations decay.
  • Aβ = 1: the amplitude is ideally constant.
  • Aβ > 1: the amplitude grows until a nonlinear mechanism reduces gain or the output clips.

7. Why amplitude stabilization matters

Exact gain adjustment is difficult because component values and op-amp gain change with temperature and frequency. A lamp, diodes, or a JFET can vary the negative feedback so that the effective gain settles at the required value.

Gentle control gives a low-distortion sine wave; hard rail clipping introduces harmonics.

8. Below and above f₀

Below f₀, the series capacitor has high reactance and the network gives a positive phase lead. Above f₀, the shunt capacitor increasingly bypasses the feedback node and the network gives a phase lag.

Only at f₀ is the network phase 0°.

9. Uses and limitations

Wien bridge oscillators are useful for audio-frequency sine-wave generation, laboratory signal sources, and low-distortion testing.

Frequency accuracy depends on R and C matching, while the upper useful frequency is limited by the op-amp bandwidth and slew rate.

Wien bridge self-check

Answer all five questions, then check your score and explanations.

Not submitted
1. For R₁ = R₂ = R and C₁ = C₂ = C, what is the oscillation frequency?

Explanation: In the equal-component Wien network, the zero-phase frequency is f₀ = 1/(2πRC).

2. What is the feedback fraction β₀ at f₀ for equal R and C values?

Explanation: At balance, the equal-component lead–lag network attenuates the output by a factor of three, so β₀ = 1/3.

3. For equal components, which non-inverting amplifier gain sustains oscillation ideally?

Explanation: Barkhausen requires Aβ₀ = 1. Since β₀ = 1/3, the required gain is A = 3, obtained with Rf = 2Rg.

4. What happens when the loop-gain magnitude Aβ₀ is less than one?

Explanation: If Aβ₀ < 1, each trip around the loop returns a smaller signal, so the envelope decreases toward zero.

5. Why is an amplitude-stabilization element used in a practical Wien bridge oscillator?

Explanation: Start-up needs loop gain slightly above one, but steady operation needs loop gain equal to one. A lamp, diode network, or JFET can reduce effective gain smoothly as amplitude rises.
