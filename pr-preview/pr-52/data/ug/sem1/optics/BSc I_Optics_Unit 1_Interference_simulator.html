Course Learning Outcomes (CLOs)
  • CLO 1: Demonstrate spatial interference produced by division of wavefront using Young's double-slit geometry.
  • CLO 2: Calculate linear fringe width $\beta = \frac{\lambda D}{d}$ and analyze its sensitivity to experimental variations.
  • CLO 3: Validate the $\cos^2$ intensity distribution curve and locate constructive ($m\lambda$) and destructive ($(m+1/2)\lambda$) phase conditions.

Key Theoretical Relations
1. Path Difference ($\Delta$): For small angles ($\theta \approx \sin\theta \approx \tan\theta = y/D$), the path difference at screen position $y$ is: $$\Delta = d \sin\theta = \frac{d \cdot y}{D}$$ 2. Fringe Width ($\beta$): Distance between two consecutive bright or dark fringes: $$\beta = \frac{\lambda D}{d}$$ 3. Intensity Distribution ($I$): Resultant intensity of two coherent waves with equal amplitude: $$I(y) = 4 I_1 \cos^2\left(\frac{\delta}{2}\right) = I_0 \cos^2\left(\frac{\pi d y}{\lambda D}\right)$$ 4. Interference Conditions: $$\text{Maxima (Bright): } y_m = m \frac{\lambda D}{d}, \quad m = 0, \pm 1, \pm 2, \dots$$ $$\text{Minima (Dark): } y_m = \left(m + \frac{1}{2}\right) \frac{\lambda D}{d}, \quad m = 0, \pm 1, \pm 2, \dots$$
