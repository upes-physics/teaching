Unit 5: Numerical Methods

Students can change initial guesses, step sizes and data values to see how numerical algorithms progress step by step.

1. Bisection Method

Find a root of f(x)=x²−2 in an interval [a,b].

Given f(x) = x^2 - 2 c = (a + b)/2 If f(a)f(c) < 0, set b = c Else set a = c

2. Newton-Raphson Method

Use xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) for f(x)=x²−2.

f(x) = x^2 - 2 f'(x) = 2x x_new = x - f(x)/f'(x)

3. Lagrange Interpolation

Interpolate y at a chosen x using three points.

P(x) = Σ y_i L_i(x) L_i(x) = Π (x - x_j)/(x_i - x_j), j ≠ i

4. Trapezoidal Rule

Approximate ∫₀¹ x² dx using n intervals.

h = (b-a)/n I = h [ (f(a)+f(b))/2 + f(x1)+...+f(xn-1) ]

5. Euler Method for ODE

Solve dy/dx = y, y(0)=1 using Euler method.

y_{n+1} = y_n + h f(x_n, y_n) For dy/dx = y: y_{n+1} = y_n + h y_n

6. Runge-Kutta 4 Method

Solve dy/dx = y, y(0)=1 for one or more steps.

k1 = h f(x, y) k2 = h f(x+h/2, y+k1/2) k3 = h f(x+h/2, y+k2/2) k4 = h f(x+h, y+k3) y_new = y + (k1 + 2k2 + 2k3 + k4)/6

7. Linear Equations: 2×2 Solver

Solve ax + by = c and dx + ey = f.

D = ae - bd Dx = ce - bf Dy = af - cd x = Dx/D, y = Dy/D

8. PDE Idea: 1D Heat Diffusion Update

Visualize one finite-difference update for the heat equation.

u_i^{new} = u_i + r (u_{i+1} - 2u_i + u_{i-1})
