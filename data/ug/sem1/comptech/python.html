Unit 2: Programming with Python

Static browser simulators for teaching Python basics, scientific programming, and data handling.

Syllabus Focus

Introduction, Python literals, operators, variables, decision making, loops, logic operators, lists, sorting list, functions, scopes, tuples and dictionaries, modules and packages, errors and exceptions, characters and strings, basic object programming, processing files, NumPy and Pandas.

1. Variables and Expressions

Change a and b to see assignment and expression evaluation.

a = 5
b = 3
c = a + b
print(c)

2. If-Else Condition

Check whether a number is even or odd.

if x % 2 == 0:
    print("Even")
else:
    print("Odd")

3. For Loop

Visualize each iteration of a loop.

for i in range(5):
    print(i)

4. Function

Understand input, processing, and return value.

def square(x):
    return x * x

5. List Operations

Enter comma-separated numbers and calculate sum, maximum, average, and sorted list.

numbers = [2, 4, 6, 8, 10]
sum(numbers)
max(numbers)
sorted(numbers)

6. Plotting Logic

Select a function and observe the plotted curve.

x = np.linspace(-10, 10, 100)
y = f(x)
plt.plot(x, y)

7. Dictionary Lookup

Use a dictionary to map student names to marks.

marks = {"Amit": 82, "Riya": 91, "Farhan": 76, "Meera": 88}
print(marks[name])

8. File Processing

Paste lines of data and simulate reading a text file line by line.

with open("data.txt") as f:
    values = [float(line) for line in f]
print(sum(values)/len(values))

9. NumPy-style Array

Generate equally spaced points similar to np.linspace.

x = np.linspace(start, stop, n)

10. Pandas-style Table

Enter marks and generate a simple dataframe-like summary.

df = pd.read_csv("marks.csv")
df["Marks"].mean()
