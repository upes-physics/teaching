Unit 3: Scientific Word Processing with LaTeX

Static simulators for writing scientific documents, equations, tables, figures, presentations, and bibliography entries.

Syllabus Focus

Introduction to LaTeX; preparing a basic LaTeX file, document classes, compiling LaTeX files, LaTeX tags for environments, commands and environments, formula and equation representation, figures, tables, bibliography, and citation.

1. Basic LaTeX Document

Generate the source for a minimal article document.



2. Equation Preview
Type an equation body and preview it using MathJax.


3. Integral and Fraction Example
Generate the integral example used in scientific reports.


4. Table Generator
Create a LaTeX table from simple rows.


5. Figure Environment
Generate source code for inserting a figure.


6. Beamer Slide
Create a simple Beamer frame.


7. Bibliography and Citation
Generate a simple BibTeX entry and citation command.
