Euler Method for Solving First-Order Differential Equations

Learning Outcomes

  • Identify an initial value problem \(y'=f(x,y)\), \(y(x_0)=y_0\).
  • Use Euler's formula to compute successive approximations.
  • Interpret Euler's method geometrically as tangent-line stepping.
  • Compare numerical values with exact/reference values.
  • Analyze error as the step size \(h\) changes.
INITIAL VALUE
IVP

Starting Point

The method begins from a known point \((x_0,y_0)\).

LOCAL SLOPE
f

Derivative

The slope at each point is calculated from \(f(x_n,y_n)\).

STEP FORWARD
h

Approximation

The tangent line predicts the next value after one step.

1. First-Order Initial Value Problem

\[ \frac{dy}{dx}=f(x,y), \qquad y(x_0)=y_0 \]

We want approximate values of \(y\) at \(x_1,x_2,x_3,\ldots\), where \(x_{n+1}=x_n+h\).

2. Euler Formula

\[ y_{n+1}=y_n+h f(x_n,y_n) \]

The method assumes that the slope at the beginning of the interval remains approximately valid throughout that interval.

3. Worked Step

For \(y'=x+y,\ y(0)=1,\ h=0.2\):

\[ f(0,1)=0+1=1 \]
\[ y_1=y_0+h f(x_0,y_0)=1+0.2(1)=1.2 \]
Key idea: smaller \(h\) usually means better accuracy, but more computation.

Layer 3 - Exploration & Applications

Applications of Euler Method

Cooling and Motion

Euler's method gives a first approximation for temperature change, velocity change, and other time-dependent processes.

Population Models

Growth and decay models can be explored step by step using Euler's formula.

Electrical Circuits

First-order circuit equations can be solved approximately when inputs vary or exact solving is inconvenient.

Numerical Simulation

Euler's method is often the first numerical solver taught because it reveals the basic idea of stepping through a differential equation.

Instructor & Student Support

Teaching Notes

Suggested Teaching Sequence

  1. Introduce the initial value problem.
  2. Draw the tangent at \((x_0,y_0)\).
  3. Use \(y_{n+1}=y_n+hf(x_n,y_n)\).
  4. Compare the Euler polygon with the exact/reference curve.
  5. Discuss truncation error and convergence.

Common Errors

  • Using \(f(x_{n+1},y_{n+1})\) instead of \(f(x_n,y_n)\).
  • Forgetting to update \(x\) after each step.
  • Using degrees/radians style thinking where no angle is involved.
  • Assuming Euler is exact for curved solutions.
