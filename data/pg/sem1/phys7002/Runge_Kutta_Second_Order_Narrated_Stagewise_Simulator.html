Layer 1 - Conceptual Understanding

Runge-Kutta Method for Second-Order Equations

A second-order initial value problem is solved by first converting it into two simultaneous first-order equations. Then RK4 is applied to both equations together.

Learning Outcomes

  • Convert \(y''=g(x,y,y')\) into a first-order system.
  • Apply RK4 to position \(y\) and velocity \(v=y'\) at the same time.
  • Compare Euler and RK4 approximations for second-order motion models.
  • Interpret displacement graph, velocity graph, and phase curve.
  • Use error and convergence feedback to judge accuracy.
SECOND ORDER
ODE

Original Form

The model is \(y''=g(x,y,y')\), with \(y(x_0)\) and \(y'(x_0)\) given.

SYSTEM FORM
2x1

Convert

Put \(v=y'\). Then solve \(y'=v,\ v'=g(x,y,v)\).

FOUR STAGES
RK4

Advance Together

Each step updates both \(y\) and \(v\) using four coupled slope estimates.

1. System Conversion

\[ y''=g(x,y,y'),\quad y(x_0)=y_0,\quad y'(x_0)=v_0 \]
\[ v=y' \Rightarrow \frac{dy}{dx}=v,\qquad \frac{dv}{dx}=g(x,y,v) \]

2. RK4 for the Coupled System

For the vector \(Y=[y,\ v]^T\), write \(Y'=F(x,Y)\). RK4 becomes:

\[ K_1=F(x_n,Y_n),\quad K_2=F\left(x_n+\frac h2,Y_n+\frac h2K_1\right) \] \[ K_3=F\left(x_n+\frac h2,Y_n+\frac h2K_2\right),\quad K_4=F(x_n+h,Y_n+hK_3) \] \[ Y_{n+1}=Y_n+\frac h6(K_1+2K_2+2K_3+K_4) \]
Key idea: RK4 must update \(y\) and \(v\) as a pair. Updating only \(y\) is a common mistake.

Layer 3 - Exploration & Applications

Applications of Second-Order RK4

Projectile and Particle Motion

When acceleration depends on time, position, or velocity, second-order ODEs appear naturally. RK4 estimates both position and velocity step by step.

Mechanical Vibrations

Spring-mass and damped oscillator equations use \(y''\), \(y'\), and \(y\). The phase plot helps students see oscillation and damping.

RLC Circuits

Second-order circuit equations can be converted into voltage-current state variables and solved using RK4.

Numerical Simulation

Second-order RK4 is widely used in classroom simulations of motion, vibration, and control systems.

Instructor & Student Support

Teaching Notes

Suggested Sequence

  1. Start with \(y''=g(x,y,y')\).
  2. Introduce \(v=y'\).
  3. Apply Euler to show basic stepping.
  4. Apply RK4 to the vector system.
  5. Discuss displacement, velocity, phase curve, and error.

Common Errors

  • Solving \(y''\) directly without introducing \(v\).
  • Updating \(y\) but forgetting to update \(v\).
  • Using different \(h\) values while comparing methods.
  • Confusing displacement graph with phase graph.
